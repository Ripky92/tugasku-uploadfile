# Tugasku Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Situs gratis "Tugasku" tempat M RIFKY ALAMSYAH mengunggah tugas BASIS DATA (PDF/Word) dan dosen Agung Santoso, M.Kom melihat serta mengunduhnya.

**Architecture:** Situs statis (HTML/CSS/JS biasa, tanpa build step) di Netlify. Supabase (CDN `@supabase/supabase-js@2`) menyediakan Auth (satu akun admin), tabel `tugas`, dan bucket Storage `tugas-files`. Logika murni (validasi file, format tanggal) dipisah ke `js/utils.js` agar bisa diuji dengan Node.

**Tech Stack:** HTML, CSS, vanilla JS (ES modules), Supabase, Netlify, Node 18+ (`node --test`) hanya untuk tes.

**Spec:** `docs/superpowers/specs/2026-10-29-tugasku-design.md`

## Global Constraints

- Nama situs: `Tugasku`; mahasiswa `M RIFKY ALAMSYAH`; mata kuliah `BASIS DATA`; dosen `Agung Santoso, M.Kom`. Tampil di header halaman publik.
- Ekstensi file yang diterima: `.pdf`, `.doc`, `.docx` saja. Batas ukuran 10 MB.
- Halaman publik tanpa login. Tulis/hapus hanya untuk pengguna login. Sign-up Supabase dimatikan.
- Tanggal unggah = `created_at` dari database. Daftar terbaru di atas.
- Antarmuka berbahasa Indonesia. CSS menarik: gradasi, bayangan kartu, sudut membulat, hover, transisi, responsif HP.
- Tanpa framework, tanpa build step, tanpa biaya.

## Review Focus

- Berkas dengan ekstensi salah (mis. `.exe`, `.pdf.exe`) atau huruf besar (`TUGAS.PDF`): `.PDF` diterima, `.pdf.exe` ditolak.
- Berkas kosong atau > 10 MB: ditolak dengan pesan jelas.
- Judul kosong/hanya spasi: ditolak.
- Nama berkas berspasi/berkarakter khusus/duplikat: di storage harus unik dan aman (tidak menimpa tugas lain).
- Daftar kosong: halaman publik menampilkan pesan "Belum ada tugas", bukan halaman rusak.
- Pengguna belum login membuka `admin.html`: diarahkan ke form login, tanpa menampilkan form unggah.

### Task 1: Fungsi murni (`utils.js`)

**Files:**
- Create: `js/utils.js`, `tests/utils.test.mjs`

**Interfaces:**
- Produces:
  - `validateTitle(title: string): string | null` — pesan error atau `null` jika valid.
  - `validateFile(file: {name: string, size: number}): string | null`
  - `buildStoragePath(fileName: string, now?: number): string` — `"<timestamp>-<nama aman huruf kecil>.<ext>"`.
  - `fileTypeLabel(fileName: string): "PDF" | "Word"`
  - `formatDate(iso: string): string` — mis. `"28 Okt 2026"` (locale `id-ID`).

- [ ] **Step 1: Tulis tes gagal** di `tests/utils.test.mjs` (`node:test`): `validateFile({name:"a.PDF",size:1})` → `null`; `{name:"a.pdf.exe",size:1}` → string; `{name:"a.pdf",size:0}` → string; `{name:"a.docx",size:10*1024*1024+1}` → string; `validateTitle("   ")` → string; `validateTitle("Tugas 1")` → `null`; `buildStoragePath("Tugas Saya (1).PDF", 123)` → `"123-tugas-saya-1.pdf"`; dua panggilan dengan `now` berbeda menghasilkan path berbeda; `fileTypeLabel("x.docx")` → `"Word"`, `"x.pdf"` → `"PDF"`.
- [ ] **Step 2: Jalankan** `node --test tests/` — harapan: FAIL (modul belum ada).
- [ ] **Step 3: Implementasikan** semua fungsi di atas di `js/utils.js` sebagai ES module (`export`), tanpa dependensi.
- [ ] **Step 4: Jalankan** `node --test tests/` — harapan: semua PASS.
- [ ] **Step 5: Commit** `git add js/utils.js tests && git commit -m "feat: add pure validation and formatting utils"`

### Task 2: Backend Supabase (`setup.sql`) dan klien (`api.js`)

**Files:**
- Create: `supabase/setup.sql`, `js/config.js`, `js/api.js`

**Interfaces:**
- Consumes: `buildStoragePath` dari Task 1.
- Produces (`js/api.js`, ES module, memuat supabase-js dari `https://esm.sh/@supabase/supabase-js@2`):
  - `listTugas(): Promise<Tugas[]>` dengan `Tugas = {id: string, judul: string, file_path: string, file_url: string, created_at: string}`, urut `created_at` menurun.
  - `uploadTugas(judul: string, file: File): Promise<void>`
  - `deleteTugas(tugas: Tugas): Promise<void>` — hapus berkas storage lalu baris tabel.
  - `signIn(email: string, password: string): Promise<void>` (melempar `Error` bila gagal)
  - `signOut(): Promise<void>`
  - `isSignedIn(): Promise<boolean>`

- [ ] **Step 1: `setup.sql`**: tabel `tugas(id uuid pk default gen_random_uuid(), judul text not null, file_path text not null, created_at timestamptz default now())`; RLS aktif; kebijakan `select` untuk `anon, authenticated`; `insert/delete` hanya `authenticated`; bucket publik `tugas-files`; kebijakan storage: baca publik, `insert/delete` hanya `authenticated`.
- [ ] **Step 2: `config.js`** berisi placeholder `SUPABASE_URL` dan `SUPABASE_ANON_KEY` (komentar: cara mengisi, lihat README).
- [ ] **Step 3: Implementasikan `api.js`** sesuai signature; `file_url` dari `getPublicUrl`; `uploadTugas` mengunggah ke storage dahulu, lalu insert baris, dan bila insert gagal menghapus berkas yang sudah terunggah.
- [ ] **Step 4: Verifikasi manual** (setelah pengguna mengisi config, lihat Task 5): `listTugas()` di konsol browser mengembalikan array kosong tanpa error.
- [ ] **Step 5: Commit** `git commit -m "feat: add supabase schema and api client"`
